# 常见问题

## 安装需要联网吗？

文件名带 `offline-full` 的完整离线包已经包含官方运行环境与模型，解压后直接启动，不需要再联网安装。轻量包首次需要取得约 0.95 GB 官方压缩包；文件已在本地时，可按 README 的 `-ArchiveDirectory` 方式离线安装。

## 完整包解压后要运行安装脚本吗？

不用，直接双击“启动语音输入.vbs”。不要只从压缩包里单独拖出启动文件；整个文件夹需要完整解压并保持目录结构。首次启动会在本目录生成运行文件夹并枚举本机麦克风。

## 为什么不是一边说一边立即出字？

默认使用上游 60 秒分段、4 秒重叠，短句通常松开后返回文字。曾尝试更短分段，但它会减少上下文；本项目不提供速度档位，也没有改造模型实现微信式实时修订。

## 普通话能否再提高准确率？

默认已经显式指定中文转写。先确认麦克风输入清晰、接口正确，常用人名、地名和专业词放入热词表；不要为追求更早出字而缩短分段。项目不提供准确率百分比承诺。

## 说话后没填进去，文字去哪了？

输入层会检查目标是否可编辑，并在可读的目标上确认内容变化。没有输入位置、只读、编辑保护中断或无法确认输入时，将最终完整结果放进剪贴板。兜底只复制，你自己 Ctrl+V；不会再次尝试粘贴。少数自定义软件可能一直需要这种方式。

## Ctrl+C、Ctrl+V 会触发录音吗？

按住说话采用 0.3 秒等待；期间按下其他键形成组合键则取消。说话键可用多个独立单键，但不要把它们同时当成一组组合快捷键。点按开始/结束建议选 F9 等功能键，避免影响日常打字。

## 没收到声音怎么办？

托盘设置中点“刷新设备”，选实体麦克风，再“测试收音”。Realtek 等普通麦克风可先试 Windows WASAPI，不能打开时尝试同名 MME 接口。检查 Windows 麦克风权限，确认没有选中虚拟声卡。

## 提示缺少 DLL？

安装 Microsoft 官方 Visual C++ x64 运行库，重新启动程序。不要从不明 DLL 下载站单独下载文件。

## 双击 VBS 无法启动？

部分 Windows 系统没有启用 VBScript。可在安装目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\start.ps1
```

如果文件被 Windows 标记为来自互联网，确认来源后通过文件属性解除阻止。项目不要求全局修改 PowerShell 执行策略。

## 如何更新或删除？

先从托盘退出。相同运行环境版本可再次运行安装器更新覆盖层，已保存的麦克风、按键、热词及高级配置会保留；更换上游运行环境版本请使用新目录。卸载前在设置中取消开机自动启动并保存，然后退出并删除安装目录。

## 录音、日志和隐私

新安装默认不归档录音；运行日志仍可能包含识别文本。启用上游音频保存功能后，音频和记录在本机目录中。提交 Issue 不要上传整个安装目录、录音或未经检查的日志。开源仓库内没有打包开发机器的个人数据。
